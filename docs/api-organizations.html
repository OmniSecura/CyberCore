GitHub Quick Start API

Organizations API Reference

Endpoints for managing organisations, roles, and members. Base URL: http://localhost:8081/api/v1

Auth required

All endpoints require an authenticated session. The service validates identity by forwarding your cookies to auth-service on each request.

Organisations

POST /organizations/ Create an organisation ›

Creates a new organisation. The authenticated user becomes the Owner automatically.

Request body

FieldTypeRequiredNotes
namestringrequiredHuman-readable organisation name
slugstringrequiredURL-friendly, globally unique, lowercase, e.g. my-company
 
curl -b cookies.txt -X POST http://localhost:8081/api/v1/organizations/ \
  -H "Content-Type: application/json" \
  -d '{"name": "ACME Corp", "slug": "acme-corp"}'

Responses

StatusMeaning
201Organisation created
409Slug already taken
GET /organizations/my List organisations I belong to ›

Returns a paginated list of all organisations where the current user is a member, with their role and member count in each.

Query parameters

ParamTypeDefault
pageint1
page_sizeint20 (max 100)

Response

{
  "total": 2,
  "page": 1,
  "page_size": 20,
  "total_pages": 1,
  "items": [
    {
      "id": "org-uuid",
      "name": "ACME Corp",
      "organization_slug": "acme-corp",
      "role": "Owner",
      "member_count": 5,
      "created_at": "2026-01-01T00:00:00Z"
    }
  ]
}
GET /organizations/{slug} Get organisation details ›

Returns a single organisation. The caller must be a member. Returns 404 if the org doesn't exist or the user is not a member (membership is not leaked).

Responses

StatusMeaning
200Organisation object with role and member count
404Not found or not a member
PATCH /organizations/{slug} Update organisation settings ›

Update the org's name or slug. Requires org.settings privilege.

Request body (all fields optional)

FieldTypeNotes
namestringNew display name
slugstringNew URL slug; must be globally unique
DELETE /organizations/{slug} Soft-delete an organisation ›

Soft-deletes the organisation. Only the Owner can do this. The slug is freed. All data is preserved and can be restored via /reactivate.

Responses

StatusMeaning
200Deleted
403Not the Owner
PATCH /organizations/{slug}/transfer-ownership Initiate ownership transfer ›

Step 1 of the two-step ownership transfer. Sends an email to the recipient. Only the Owner can initiate. The recipient must already be a member.

Request body

FieldTypeRequired
new_owner_idstring (UUID)required
POST /organizations/transfer-ownership/accept Accept ownership transfer ›

Step 2 of ownership transfer. The recipient calls this with the token from their email. Token is single-use; previous owner's role changes to Member.

Request body

FieldTypeRequired
tokenstringrequired

Responses

StatusMeaning
200Ownership transferred; returns new slug/name
404Token not found
410Token expired
403Not the intended recipient
POST /organizations/{org_id}/reactivate Reactivate a deleted organisation ›

Restores a soft-deleted organisation. Use the org's UUID (not slug — slug may have been freed). Only the original Owner can reactivate.

Request body

FieldTypeRequiredNotes
new_slugstringoptionalRequired only if the original slug was claimed after deletion

Responses

StatusMeaning
200Reactivated; returns current slug
409New slug is already taken

Roles & Privileges

GET /organizations/roles/privileges List all available privileges ›

Returns the full privilege registry grouped by category. Used by the role editor UI to display available privileges. No auth required.

{
  "scans": ["scans.run", "scans.view", "scans.manage"],
  "members": ["members.view", "members.invite", "members.remove"],
  "roles": ["roles.view", "roles.manage"],
  "organisation": ["org.settings"]
}
GET /organizations/roles/{slug}/my-privileges Get my privileges in an org ›

Returns the set of privileges the current user holds in the organisation. Called by scan-service (and other services) to enforce access control.

{ "privileges": ["scans.run", "scans.view", "members.view"] }

Returns an empty list if the user is not a member (does not reveal membership status — 404 is only returned if the org doesn't exist).

GET /organizations/roles/{slug} List roles in an org ›

Returns all roles defined in the organisation. Requires roles.view.

[
  {
    "id": "role-uuid",
    "name": "Security Analyst",
    "description": "Can run and view scans",
    "color": "#3fb950",
    "privileges": ["scans.run", "scans.view"],
    "is_system": false
  }
]
POST /organizations/roles/{slug} Create a custom role ›

Creates a new role. Requires roles.manage. The creator cannot assign privileges they don't themselves hold (prevents privilege escalation).

Request body

FieldTypeRequiredNotes
namestringrequiredDisplay name
descriptionstringoptional
colorstringoptionalHex color e.g. #3fb950
privilegesarray[string]requiredList of privilege strings
PATCH /organizations/roles/{slug}/{role_id} Update a role ›

Updates an existing role's name, description, color, or privileges. Requires roles.manage.

DELETE /organizations/roles/{slug}/{role_id} Delete a role ›

Deletes a custom role. Requires roles.manage. System roles (Owner) cannot be deleted.

Responses

StatusMeaning
200Role deleted
403Cannot delete system roles or missing privilege
